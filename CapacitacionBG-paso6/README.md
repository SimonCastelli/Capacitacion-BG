# CapacitacionBG

## Descripción

Este proyecto contiene código de capacitación y ejemplos de programación.

## Estructura del Proyecto

El código principal se encuentra en el archivo **`Program.cs`**, donde se implementan los ejemplos y funcionalidades principales del proyecto.

## Cómo ejecutar

```bash
dotnet run
```

## Requisitos

- .NET SDK instalado
- Visual Studio Code o IDE compatible
- Postman (para probar los endpoints de la API)

## Explicación del Código

Este proyecto implementa una API REST con los siguientes métodos HTTP:

### Métodos HTTP

- **GET**: Recupera datos existentes del servidor
- **POST**: Crea nuevos recursos en el servidor
- **PUT**: Actualiza recursos existentes completamente
- **DELETE**: Elimina recursos del servidor

Postman se utiliza para pruebas interactivas de estos endpoints, permitiendo enviar solicitudes y validar respuestas fácilmente.
